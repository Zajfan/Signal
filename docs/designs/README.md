# Interface design references

These six HTML exports preserve the 12ui-generated marketplace references used for the local application. They contain illustrative design content, not production jobs. The runtime serves `index.html` and `web/`, uses API-backed data, and does not expose this directory.

The application adapts the shared cream, forest-green and lime visual system to real forms, source review, separate public job URLs and responsive layouts. Browser checks cover desktop/mobile behavior and screenshots; these references are not a claim of pixel-identical implementation.

The design service exported all six pages. Its combined prototype assembly failed. A later automated comparison of the live local app was blocked by approval review because that operation could export local page/repository content to the external service. Local screenshots were reviewed instead; the external comparison remains unperformed.
